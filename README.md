# Mineralz Heritage

This project was generated using the [Bevy New 2D](https://github.com/TheBevyFlock/bevy_new_2d) template.
Check out the [documentation](https://github.com/TheBevyFlock/bevy_new_2d/blob/main/README.md) to get started!

**As per the arcade map description**

- Gather 6 different types of minerals to survive the incoming zerg attacks.
- Divide up roles and cooperate.
- Keep your Probe alive. If it dies, you lose.
- Kill the Nydus Worm to win.


## Dissect the fun

I find this map fun for several reasons, some of which i will try to port to this prototype.

- To find a defendable position -> Makes player think tactically at the beginning.
- How to defend said position -> Makes player optimize building placements. Multiple building are suited, each with a different playstyle to discover.
- Team roles -> To be efficient when playing with other players, each player must do its part. Roles can be picked in order to facilitate this.
- Resource gathering -> What and how to gather at the beginning is a crucial step toward success.
- Meta-progression -> Between each death, players gain more passive talents, skins, active skills. It appeals to long-term progression.
- Exploration -> After a certain amount of night, players need rare resources only obtainable through map exploration which is dangerous at night-time.
